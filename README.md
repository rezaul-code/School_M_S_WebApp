# 🎓 School Management System Web Application

A modern and professional School Management System built using **React + TypeScript + Vite** with responsive UI and modular architecture.

---

## 🚀 Live Demo

🌐 https://school-m-s-web-app.vercel.app

---

## ✨ Features

- 👨‍🎓 Student Management
- 👨‍🏫 Teacher Management
- 💰 Fee Structure Management
- 📅 Academic Year Management
- 📊 Dashboard Analytics
- 🔐 Authentication & Protected Routes
- 📱 Fully Responsive Design
- 🎨 Modern UI with Tailwind CSS
- ⚡ Fast Performance using Vite
- 🧩 Modular Component Architecture

---

## 🛠️ Tech Stack

| Technology | Usage |
|------------|-------|
| React | Frontend Library |
